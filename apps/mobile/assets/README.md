# Application icon

`icon.png` is a 1024px render of the original Phase 1 vector at `design/assets/app-icon.svg`, not a third-party logo. It is a development composition; final adaptive/monochrome mask exports still need release review. Manrope font binaries come from the pinned `@expo-google-fonts/manrope` package. `manrope-license.json` preserves its complete `LICENSE_FONT` text and is bundled/displayed by the About screen so redistribution rights accompany the font assets.
